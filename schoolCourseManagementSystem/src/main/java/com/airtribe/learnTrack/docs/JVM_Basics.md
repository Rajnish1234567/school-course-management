What is JDK, JRE, JVM?

    JDK stands for Java Development Kit. It contains all the development tools, external required library, compiler, 
    JIT and debugger, and JVM. JDK compiler is responsible to compile the java source code and generates the bytecode.

    JRE stands for Java Runtime Enviroment. It contains the library which are required and other tools like debugger,
    JVM which are required at the run time.

    JVM stands for Java Virtual Machine. It contains tools like debugger, JIT(Just In Time). It executes the byte code
    and generates into Machine code which is undestood by the opreating system. To increase the efficiency of CPU it 
    uses JIT by executing the commonly used code and converting to machine level language or Low level language.
    

What is bytecode?

    When we create any file in java then it is created as .java i.e. if we create Employee class then file is created as
    Employee.java and it is called as source code, But on compilation the compiler generates the .class file i.e means
    Employee.class and this is known as byte code.

What does “write once, run anywhere”?

    Java follows WORA principle which means Write Once, Run Anywhere. It means the code written and compiled in one 
    operating system and be run in any other operating system. Irrespective of the operating system the code in Running
    state produce same result and same behaviour. 
    
    Although each operating system has different JDK implementation but for same code they will produce same result.
